# 常用表达词库（英文 → 中文）

> 本文件是 `demo/phrases.js` 的**配套说明书**，给不写代码的内容同学看。
> JS 里改了句子，这里的表格也要跟着改（见文末「维护说明」）。
> 最后同步：2026-10-07 ｜ 共 170 条固定句、31 个模板。

## 一、这是什么

这是「China Hand」离线短语库的完整清单。用户在搜索框里输入英文（例如 `allergy`、`toilet`、`too expensive`），
App 就从这里匹配出一句现成的中文，用户把手机递给对方看。

每条记录分两种：

- **固定句**：一句话就是一句话，例如「请问洗手间在哪里？」。
- **模板**：句子里有一个 `%s` 空位，由下面「填充」表里的词替换。例如「我对 **%s** 过敏。」可以填「花生」「海鲜」等。

所有记录分成 13 个分类（`cat`）：

| 分类 slug | 中文 | 覆盖内容 |
|---|---|---|
| `basics` | 日常 | 问候、厕所、纸巾、电梯、听不懂等随时会用到的一句话（20 条） |
| `food` | 餐饮 | 点菜、忌口、口味、打包、买单（20 条） |
| `taxi` | 打车 | 上车点、指路、付款方式、让司机等一等（17 条） |

## 二、写作规则

以下规则与 `docs/05-内容模板规范.md` 一致，改内容前请先读一遍。

| 规则 | 说明 |
|---|---|
| 英文按 CEFR B1 | 句子简单、口语，让人一眼看懂，不堆生词。 |
| 英文是「用户会打进去的搜索词」 | 不是书面散文，尽量动词开头，单句不超过 15 个单词。 |
| 中文要礼貌、完整、能独立示人 | 中文是递到陌生人眼前的那句话，不能依赖对方看过上一张卡片。 |
| 简体中文 + 中文标点 | 用「，。？！」，不用英文标点。 |
| 不做承诺 | 医疗、支付类只写「我想说清什么」，不承诺结果，不诊断、不建议用药。 |
| 避免本地术语 | 不出现需要本地背景才懂的词；必须出现时先用一句话解释。 |
| `%s` 规则 | 模板的英文和中文里必须各有一个 `%s`，位置对应；固定句里不能有 `%s`。 |
| 关键词 `keys` | 固定句才有。提供同义词、英式/美式/印度式说法、常见拼错、相关名词，全小写、不加标点，让「翻译式」搜索也能命中。 |
| 填充 `fill` | 只有模板才有，每个模板 6–15 个填充，每个填充有英文、中文、关键词。 |

## 四、维护说明

1. `demo/phrases.js` 和本文件是**同一个词库的两个视图，必须一起改**。只改一边，两边就会对不上。
2. 这一份词库的流程是：**先改 JS，再重新生成本文件**。
   本文件有 201 条记录、两百多行表格，靠手工在两份文件之间对齐必然漂移；
   所以顺序固定为「改 `demo/phrases.js` → 重新生成 `content/cards/常用表达词库.md`」，不要反过来在本文件里直接改。
3. 改完 JS 后，至少核对：`%s` 数量英文与中文一致、分类只能是那 13 个 slug、每条都有英文/中文/图标/分类/关键词。
4. 新增或删除条目后，记得更新本文件顶部「最后同步」的日期和条数。
