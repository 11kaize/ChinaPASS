# 双语急救卡片库

> 使用方式：用户遇到沟通困难时，一键全屏展示中文列，直接把手机给对方看。
> 卡片规范：中文列字号 ≥ 32px，英文列作为用户自己确认用的对照，展示时可隐藏。

---

## 1. 打车 Taxi

| 英文 | 中文 |
|---|---|
| I am at Exit B. | 我在 B 出口。 |
| I am wearing a black jacket. | 我穿着黑色外套。 |
| Please wait 2 minutes. | 请等我 2 分钟。 |
| I don't speak Chinese. | 我不会说中文。 |
| Please take me to this address. | 请带我去这个地址。 |
| Please use the meter. | 请打表。 |
| Please stop here. | 请在这里停车。 |
| How much is it? | 多少钱？ |
| Can I pay by Alipay? | 可以支付宝付款吗？ |
| Please show this to the driver. | 请把这段给司机看。 |

**完整打车卡片**

> 你好，我不太会说中文。
> 请带我去这个地址：
> [地址]
> 谢谢！

## 9. 海关 / 入境 Customs & Entry

> 政策类内容：只写操作步骤，不做法律判断，不承诺一定能入境。
> 官方来源：国家移民管理局 https://www.nia.gov.cn/ ｜ 海关总署 http://www.customs.gov.cn/

| 英文 | 中文 |
|---|---|
| I am a foreign tourist. | 我是外国旅客，来旅游。 |
| I will stay for [ ] days. | 我会在这里停留 [ ] 天。 |
| I am staying at this hotel. | 我住在这家酒店。 |
| I don't speak Chinese. Please find an interpreter. | 我不会说中文，请帮我找翻译。 |
| How do I fill in the arrival card? | 请问入境卡怎么填？ |
| Where is the baggage claim? | 请问取行李的地方在哪里？ |
| My luggage did not arrive. | 我的行李没有到。 |
| Do I need to declare this? | 这个需要申报吗？ |

**完整入境卡片**

> 你好，我是外国旅客，我不太会说中文。
> 请问取行李的地方在哪里？
> 我住在这个酒店，地址是：
> [酒店中文地址]
> 谢谢！

## 与 demo 的对应关系

`demo/data.js` 的 `CARD_GROUPS` 以本文件为源头，但做了扩展（14 组 / 96 张）。
新增卡片必须先补进本文件，再接进 demo，否则两边会脱节，后期接 Notion / Supabase 时对不上。

| 本文件 | demo 的 group key |
|---|---|
| 1. 打车 | `taxi` |
| 2. 外卖 | `food` |
| 3. 酒店 | `hotel` |
| 4. 医院 | `hospital` |
| 5. 丢失物品 | `lost` |
| 6. 手机没电 | `phone` |
| 7. 找路 | `directions` |
| 8. 报警 / 求助 | `emergency` |
| 9. 海关 / 入境 | `customs` |
| 10. 厕所 / 日常 | `toilet` |
| —（demo 另有） | `pay` `sim` `metro` `train` |

**合规提示**：`hospital` 组的警示语（「只用于沟通，不构成医疗建议」）在 demo 里对应 `CARD_GROUPS.hospital.note`，新增医疗类卡片组时沿用同样写法。
