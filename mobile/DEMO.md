# ChinaBuddy 手机演示流程

## Windows 与桌面 iPhone 布局预览

安装 Node.js 22.13 或更新版本，在仓库根目录运行 `npm run demo:ios`。Windows 也可以双击 `Start-ChinaBuddy.cmd`；无需 Bash/WSL。Linux 运行 `./Start-ChinaBuddy.sh`。两种脚本都会检查依赖、选择可用端口并自动打开浏览器中的演示页面。终端保持开启，首次启动会自动安装依赖。本地浏览器打开 iPhone 尺寸的交互预览，同时可用 Expo Go 在同一局域网的 iPhone 上运行真正的原生应用。Windows 防火墙如询问 Node.js 网络权限，只需允许当前私人网络。

桌面预览不是 Apple iOS 模拟器。真正的 iOS 模拟器需 macOS/Xcode；浏览器中的玻璃是视觉近似，真实 iOS 材质在 iPhone 上使用系统实现。浏览器的跨域限制可能阻止模型请求，真实 API 接入请在手机验证。

## 启动

电脑运行 `npm run demo`，手机安装 Expo Go。Android 用 Expo Go 扫描终端二维码，iPhone 用相机扫描二维码后进入 Expo Go。手机和电脑需在同一网络。首次启动在欢迎页选择语言，点击开始使用。

当前只演示原生交互与设计，不要求生成 APK 或独立 iOS 安装包。继续修改代码时用 `npm run mobile`；演示模式重启服务后应在 Expo Go 中重新加载项目。Expo Go 的浮动 Tools 按钮可以拖开，避免遮挡应用控件。

## 三分钟演示

快速体验账号功能：在登录页点击 **一键登录 Demo 账号 / One-tap demo sign-in**，无需填写邮箱或密码，直接进入 `ChinaBuddy Demo` 并获得 Pro 演示权益（无扣款）。重复进入复用同一本机账号并刷新演示额度。真实模型问答仍需自行连接 API；普通指南和卡片不要求登录。

1. **Today：** 选择入境口岸，查看中文全名并打开大字卡片；进入落地流程选择一个任务，返回查看“当前任务”。海港和铁路有流程差异提示。未编写城市详情的口岸有明确说明。也可手动选择城市和旅程阶段，打开准备清单勾选一项。
2. **Guides：** 打开 Taxi 指南，展开步骤并标记完成，查看备用方案和“直接去办”入口。点击 DiDi 官方入口，打开系统浏览器，然后返回指南。九个指南共保留 21 条入口及其语言、账号条件。
3. **Cards：** 搜索 `hotel`，展示一张中文卡片，收藏、复制或隐藏释义。带空白的短句需要填写后才能展示。
4. **地址卡：** 在 Today 或 Settings 输入已经确认的中文目的地地址，生成大字展示卡。地址不会自动传给 AI。
5. **AI：** 未接入模型时，点击一个建议问题，查看明确标注的预设示例与相关指南入口。
6. **真实模型：** 进入连接设置，选择服务商并输入自己的 API Key。Qwen 的区域必须与 Key 对应，可填写业务空间 ID。阅读发送说明，开启同意，测试连接后连接当前会话。测试和聊天会使用服务商额度。
7. **上下文：** 点击聊天页信息按钮，查看助手获知的信息；关闭旅程共享后，个人旅程与设备环境不进入后续请求。
8. **Settings：** 切换深色主题或界面语言。断开模型会清除 API 配置与聊天；离开应用进入后台、关闭程序或重启都会清除 AI 会话及 Key，返回后需要重新输入。

离线内容可在飞行模式下继续浏览。没有用户 Key 的预设示例不调用模型。真实模型依赖服务商账号权限、余额和设备网络。

## 新增工具演示

1. **面对面翻译：** 从首页或 Cards 进入。免费账户先查看权益说明，在本机演示会员页开通 Plus 或 Pro（不扣款），返回后阅读发送说明并开始。输入 `Can we sit here?`，上半屏倒置显示中文；上半屏改为 `可以，请坐。`，下半屏同步英文。检查暂停、恢复、清空；刷新后重新同意，文字不保留。
2. **离线搜索：** 首页搜索 `foreign card`，同时查看指南正文、FAQ 和求助卡；点击结果定位原文。换成 `Hongqiao`，展开城市机场/车站，保存为地点。
3. **行程本：** 在地址钱包保存一个地点，添加日期与 14:30 的事项并关联它；从事项出示中文地点卡，再标记完成。所有时间是中国当地时间。
4. **人民币账本：** 设置预算 ¥1,500，记住宿 ¥500、交通 ¥80，看到总支出 ¥580、剩余 ¥920；修改支出后汇总同步变化，刷新后记录保留。
