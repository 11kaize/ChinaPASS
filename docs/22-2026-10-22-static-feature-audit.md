# 静态 Demo 功能审查与实现（2026-10-22）

## 审查范围

由一个 subagent 只读检查现有代码，再按用户要求重新筛选：只考虑纯前端、本机可完成、演示直观的来华生活工具。账号后端、真实支付、人工审核、运营工单不属于这轮范围。

现有指南、单向中文卡片、阶段选择、准备清单和社区搜索均已存在，不当作新功能重复建设。

## 本轮实现

### 双向沟通板

- 新页面 `/talk`，卡片页、个人页、首页工具箱以及中文大卡均有入口。
- 从内置卡片、短语及自制卡中选择非模板问题，或从指定地点中文卡带入目的地。
- 按问句形式提供“可以/不可以”“有/没有”“是的/不是”，并有等候、跟随、查看、写下等固定中英答复。
- 英文肯定/否定保持中性的 Yes/No：避免将“这个座位有人吗”的“有”错误解释成“有空位”，或把工作人员“可以帮你”翻成“You can”。
- 金额模式只接受非负 CNY 数字，最多六位整数、两位小数，以整数分处理；不翻译自由输入，不产生支付。
- 对方的本次答复不持久化；无需网络、账号或 AI Key。

### 地址钱包

- `/address` 改为多地点管理，`/place-edit` 支持新增和编辑，最多 30 个。
- 旧单地址以 `legacy-address` 兼容显示，保存后纳入钱包；不丢弃旧地址。
- 支持酒店住处、交通、学校和其他类别，中文目的地、地点电话、搜索、默认地点和删除确认。
- 现有口岸及八个城市的机场、车站可作为收藏起点；重复机场名称合并。内置的是地点名称，不假装提供实时导航或精确街道信息。
- 任意地点可出示中文大卡；默认地点继续供原地址卡、模板使用。删除默认地点回退剩余首项，删空时清空默认与旧地址。
- 持久化采用字段白名单；不自动加入 AI 上下文；清除本机数据也会清除钱包。

### 附件回收修复

- 删除自己的帖子前先删除对应 IndexedDB / 原生文档附件。失败保留帖子并显示重试提示；可重复清理已删除的附件。
- 发布页移除附件时，清理失败不再悄悄从列表消失；离开未发布页面及异步附件加载结束时增加尽力清理。
- 已发布帖子的附件不会被发布页卸载清理。

### 卡片编辑与免费翻译（用户追加）

- 内置卡片和短语大卡提供“编辑模板”，保存为新的自制卡；自制卡可修改原卡或另存副本；卡片页原有加号继续创建新卡。
- 中英文均可编辑，预览后手动保存；自制卡中的 `%s` / `[空位]` 仍可在出示时填写。
- 接入 MyMemory 的免 Key GET 翻译接口，支持 English → 中文、中文 → English。翻译入口默认折叠、不自动请求；每次发送都需重新同意当前文字发送到 MyMemory。
- 编辑文字、切换方向、进入后台会撤销同意；请求可取消、15 秒超时、卸载后不写入响应。翻译先进入预览，用户再决定是否填入和保存。
- 请求只附带当前源文字、语言方向与启用机器翻译的参数，不读取 AI Key、账号、地址钱包、聊天或邮箱。服务商仍可获取 IP 等常规联网信息；常见密钥/密码格式会在请求前拦截。
- 官方当前限额是每次 500 UTF-8 字节，匿名每日 5,000 字符。MyMemory 会处理并可能长期保留内容，因此界面明确要求只用于普通短句，不发送隐私信息。
- 实际接口与前端调用：`Please take me to the airport.` → `请带我去机场。`；`谢谢。` → `Thanks.`。检查了预览未自动改写中文、保存新卡、自制卡原 ID 修改、空位模板另存后的填写界面。

官方依据（2026-10-22 核对）：[API 规范](https://mymemory.translated.net/doc/spec.php)、[使用限额](https://mymemory.translated.net/doc/usagelimits.php)、[条款与隐私](https://mymemory.translated.net/terms-and-conditions)。LibreTranslate 的官方托管服务需要付费 Key，自托管虽免费但需要额外服务，不作为本次静态 Demo 的默认接入：[官方文档](https://docs.libretranslate.com/)。
