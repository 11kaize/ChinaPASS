# 五、产品定位

本产品不是一个普通的旅游攻略网站，而是一个：

> **「外国人在中国生活的实时通关工具」**

它不是告诉用户「中国有什么」，而是告诉用户：

> **「现在该点哪里、该说什么、该避开什么、下一步做什么。」**

## 产品关键词

- 场景化
- 分步指引
- 避坑
- 双语沟通
- 即用即走
- 免下载
- 本地化

---

# 六、产品目标

## 1. 用户目标

帮助外国用户在 **3 分钟内完成一个具体任务**，例如：

- 成功绑定 Alipay；
- 成功打到一辆车；
- 成功买到高铁票；
- 成功点一份外卖；
- 成功入住酒店；
- 成功联系司机或前台。

## 2. 产品目标

第一阶段实现：

1. 提供 10 个高频生活场景的通关指南；
2. 提供双语急救卡片；
3. 提供外国用户常见问题 FAQ；
4. 支持移动端网页或小程序访问；
5. 支持扫码即用，不强制注册；
6. 支持英文界面。

## 3. 商业目标

第一阶段不以直接收费为主，而是验证：

- 外国用户是否真的需要；
- 是否愿意收藏；
- 是否愿意分享给同行者；
- 旅行社、酒店、青旅是否愿意合作；
- 是否能形成稳定流量入口。

# 八、产品形态设计

## 1. 不建议第一版做原生 App

原因：

- 外国游客停留时间短；
- 不愿意下载新 App；
- 推广成本高；
- 开发周期长；
- 审核复杂。

## 2. 第一版可选形态

### 方案 A：移动端网页 / PWA ★★★★★

优点：

- 扫码即开；
- 不需要下载；
- 开发快；
- 可以放在任何渠道；
- 支持多语言。

### 方案 B：微信小程序 / 支付宝小程序 ★★★★

优点：

- 中国场景内使用自然；
- 分享方便；
- 可以结合支付场景。

风险：

- 外国用户未必熟悉小程序；
- 微信 / 支付宝账号可能受限。

### 方案 C：Notion / Softr / Glide 快速搭建 ★★★★★

优点：

- 第一周就能做出 MVP；
- 适合验证需求；
- 修改成本低。

## 3. 推荐路线

| 阶段 | 做法 |
|---|---|
| **第一阶段** | 使用 Notion + Softr / Glide 做移动端网页版 |
| **第二阶段** | 如果验证成功，再开发微信小程序或轻量 App |
