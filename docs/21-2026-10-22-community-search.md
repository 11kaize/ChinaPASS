# 社区独立搜索页（2026-10-22）

- 社区首页只展示搜索入口与帖子，不再渲染热度榜。
- 点击搜索入口打开 `/community-search`，自动聚焦输入框，展示最近七天热榜，最多十条，保留原有热度计算逻辑。
- 输入时展示相关帖子建议；点击搜索或键盘搜索键后展示结果，支持综合、生活经验和求助分类筛选。
- 点击热榜或建议先进行对应搜索，再由结果打开帖子；从详情返回保留关键词和结果。
- 清空关键词返回热榜，同时展示本次搜索页内的最近搜索；历史可清除，未加入持久化存储。
- 空榜、空结果、中英文文案与深浅色配色均有对应界面。直接打开搜索页时，返回按钮以社区为无历史兜底。
- 新路由加入 AI 可信页面目录和 GitHub Pages 构建检查，支持直达与刷新。
