## 落地流程与资料依据

主页“查看落地指南”直接进入完整清单，不再要求先选口岸后返回主页再次打开；清单内可更换口岸。

流程包括：证件准备、入境卡、边检、行李、海关、通信、支付、前往住处、住宿登记、第一晚检查。清单仅记录进度，不代填表、提交登记或进行预订。口岸现场顺序、个人入境资格和服务商交易条件需以实际要求为准。

资料于 2026-10-28 复核：

- [国家移民管理局：入境卡官方免费填报及现场替代渠道](https://www.nia.gov.cn/n741440/n741577/c1755806/content.html)。线上入境卡与签证、海关申报不同。
- [国家移民管理局：非旅馆住宿登记全国推广公告](https://en.nia.gov.cn/n147418/n147468/c237295/content.html)。采用 2026-09-21 全国推广后的说明，未沿用早期七地试点范围。旅馆负责旅馆住宿登记；个人住所由本人或留宿人在抵达后 24 小时内登记，线上和现场渠道均保留。
- [中国海关：进出境旅客行李物品监管](https://online.customs.gov.cn/static/pages/guides/000629014002/000629014002.html)。需要申报或不确定时咨询海关、走申报通道。
- [中国政府：在华生活服务指南](https://english.www.gov.cn/2025special/bizexpatsinchina2025)。参考通信、支付、交通和公共服务信息，没有据其旧版内容推断当前个人签证资格。
- [商务部：便利境外人员住宿措施](https://www.mofcom.gov.cn/zwgk/zcfb/art/2024/art_10ddb29858c24ece86b3f575bda1d9c4.html)。删除“外国旅客必须找特殊涉外资质酒店”的笼统说法。
- [铁路 12306 官方问答](https://www.12306.cn/en/faq.html?item=1)。护照购票、使用同一证件及人工核验；不承诺具体改签条件或所有闸机均可自动识别。
- [机场国际到达流程](https://www.hzairport.com/en/ride/arrive.html)。作为行李、现场标识和抵达流程的实践参考，不假定每个口岸布局相同。

九项单任务指南均重新整理，删除固定票价/退款时限、必定可用的应用功能、紧急就医必须先出示护照等不可靠概括。城市说明区分机场、航站楼和车站，避免承诺固定交通耗时。

## 语言与本机数据

- `i18n.ts`：四种语言各 170 个完整核心键，不再以整份英文展开作为日、韩界面回退。
- `locales/reviewed.json`：人工整理的静态界面及词汇表；无联网运行时翻译，不上传用户输入。
- `guide-revisions.mjs` 与 `arrival-guide.ts`：四语任务内容；207 条短句/模板及其填空标记完成对齐检查。
- `sync-content.mjs`：缺少任何规定语言时构建失败。`npm --prefix mobile run audit:locales` 检查字典完整性、940 组四语内容、模板及地名。
- 中文提示卡的展示正文继续用中文，旁边释义和按钮使用所选语言。用户自写帖子、地址、问题、卡片及技术模型标识保留原文。
- 更名兼容旧的本机数据：迁移偏好/社区键与默认演示身份引用，保留附件数据库，避免更名后附件丢失。任意用户正文不会被批量改写。
- 只重置九项改写指南的旧步骤完成索引；其他准备清单、卡片、地址、行程等仍保留。

## AI 会话与密钥

配置表单和活动配置仅使用 React 内存状态。偏好持久化采用白名单，不包含密钥、模型配置或聊天。刷新、关闭页面、原生进入后台或主动断开会清空会话；恢复缓存页面也会清空。固定示例不加入真实请求历史。

本次未使用真实 API 密钥。连接失败检查仅使用虚构密钥与保留的无效域名；不代表已完成三家服务商真实账号的在线验证。

## 动效

根据 [Morphicons 官方文档](https://www.morphicons.com/docs) 与 subagent 复审，继续使用现有 22 个本地 Phosphor 形状。发布导出固定清理 Metro 缓存，避免更名后的包仍内嵌旧应用清单。

保留 `330/34` 弹簧、稳定形状对象及连续操作的速度延续，不新增循环图标动画。

原生系统设置查询完成前先减少动画，查询失败保持静态。网页隐藏时取消在途页面转场，恢复时不重播。系统减少动态效果、页面失焦与后台控制继续有效。原生 SVG 形变使用 JS 帧调度，未宣称 UI 线程运行或实测真机帧率。
