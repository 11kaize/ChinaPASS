# 十六、验证指标

项目是否成立，不要只看「我们觉得有用」，要看真实数据。

---

## 1. 用户侧指标

| 指标 | 说明 |
|---|---|
| 扫码率 | 多少外国人愿意扫码 |
| 停留时间 | 用户是否认真看内容 |
| 完成率 | 用户是否看完某个场景 |
| 收藏率 | 是否愿意保存 |
| 分享率 | 是否愿意分享给同伴 |
| 求助卡片使用率 | 是否展示给中国人看 |

## 2. 内容侧指标

| 指标 | 说明 |
|---|---|
| 最受欢迎场景 | 哪个场景点击最多 |
| 最高流失步骤 | 用户在哪一步卡住 |
| 最常见问题 | 用户反复问什么 |
| 最常用卡片 | 哪些双语卡片最实用 |

## 3. 渠道侧指标

| 指标 | 说明 |
|---|---|
| 青旅合作数量 | 是否愿意放二维码 |
| 旅行社合作数量 | 是否愿意推荐 |
| 社媒点击量 | 视频 / 帖子是否带来访问 |
| 线下转化量 | 地推带来多少用户 |

# 十七、商业模式设计

---

## 1. 第一阶段：免费获客

对外国用户免费。原因：

- 游客对付费敏感；
- 工具类产品需要先建立信任；
- 免费更容易传播。

---

## 2. 第二阶段：渠道合作

可合作对象：

- 青年旅舍
- 酒店
- 入境游旅行社
- 语言学校
- 大学国际处
- 机场 / 高铁服务台
- 外国人社群

---

## 3. 第三阶段：可能盈利方式

### 模式一：旅行社订阅服务

为入境游旅行社提供「外国旅客落地工具包」。

**旅行社收益：** 降低客户咨询量、提升游客体验、减少客服压力。

### 模式二：酒店 / 青旅增值服务

酒店前台放置二维码卡片。

**收益：** 提升外国住客满意度、减少前台解释成本。

### 模式三：本地服务推荐

推荐方向：包车服务、本地向导、电话卡服务、旅游保险、翻译服务、特色体验项目。

> ⚠️ 注意：推荐内容必须真实可靠，不能损害用户信任。

### 模式四：内容授权

将内容授权给：旅游平台、航空公司、机场、酒店集团、OTA 平台。

---

## 商业画布速览

| 模块 | 内容 |
|---|---|
| **客户细分** | 短期来华外国人；入境游旅行社；涉外酒店/青旅 |
| **价值主张** | 3 分钟解决一个具体落地任务，免下载、免注册 |
| **渠道** | 二维码卡片、酒店前台、社媒短视频、旅行社 |
| **收入来源** | 渠道订阅、内容授权、本地服务推荐佣金 |
| **关键资源** | 高质量双语 SOP 内容 + 真实截图 |
| **关键活动** | 内容生产与维护、渠道拓展、用户测试 |
| **成本结构** | 人力为主，技术成本极低 |
| **核心指标** | 扫码率、完成率、分享率、合作点数 |
