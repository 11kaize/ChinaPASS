# 同类产品观察与功能取舍

本次只做了方向性扫描，不代表完整的竞品评测。面向来华旅客的旅行指南和工具通常把支付、地图、翻译、交通、铁路和离线备份列为行前准备的重点。政府英文指南也介绍了境外旅客使用移动支付、打车和城市交通的办法；Trip.com 的支付指南说明旅客会在支付工具设置上遇到专门的准备步骤。

## 这版 Demo 的落实

- **行前清单：** 把付款方式、中文地址、离线翻译、车票信息和紧急联系人列为准备项。勾选保存在当前设备。
- **实用旅行指南：** 保留仓库中的 8 个完整场景，覆盖行前材料、步骤、易错点、备选方案、问题排查及来源。
- **情境短句：** 保留 12 组 82 条中英短句，新增全局搜索、收藏和全屏递屏显示。
- **离线入口：** PWA 缓存应用外壳和静态内容。Electron 桌面版直接从本地文件运行。
- **紧急电话：** 首页直接提供 110、120 和 119 拨号链接。它们依赖设备电话能力，不是应用内求助服务。

## 当前明确没有接入

地图路线、支付、打车、铁路购票和实时翻译都需要官方服务、不断更新的城市资料或第三方接口。当前静态 Demo 没有这些服务的集成，也不应把准备清单描述成预订功能。下一阶段适合先补充经过核对并带来源的城市信息包，再决定是否接入实时服务。
