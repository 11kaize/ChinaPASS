# 二十、项目成功标准

如果一个外国用户在以下任意场景中，通过你们的产品**独立完成任务**，就说明项目成立：

1. ✅ 成功用 Alipay 完成一笔支付；
2. ✅ 成功打车到酒店；
3. ✅ 成功买到一张高铁票；
4. ✅ 成功点一份外卖；
5. ✅ 成功办理酒店入住；
6. ✅ 成功向司机或前台展示中文求助卡片；
7. ✅ 成功解决一次支付失败或沟通失败。

> **关键词是「独立」**：全程没有中国朋友在旁边帮忙。这是本项目最硬的一条验收线。

---

# 二十一、总结

**China Cheat Sheet / 中国落地通关助手** 的核心价值不是做一个「大而全」的中国攻略，而是解决外国人在中国落地后的具体摩擦：

- 支付不会；
- 打车不会；
- 买票不会；
- 订酒店不会；
- 点外卖不会；
- 沟通不会；
- 遇到问题不知道找谁。

产品的关键词是：

> **场景化、分步指引、双语卡片、避坑、扫码即用、电子导游。**

第一阶段不要追求复杂技术，而要快速做出内容，找到真实外国用户，验证他们是否真的愿意使用、收藏和分享。**只要这个验证成立，项目就有继续扩大的空间。**
