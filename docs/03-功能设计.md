## 功能一：场景化通关指南（核心功能）

用户进入首页后，不看到复杂菜单，而是看到「**我要做什么**」。

### 首页场景示例

| 场景 | 说明 |
|---|---|
| Pay | 如何使用 Alipay / WeChat Pay |
| Taxi | 如何打车、联系司机 |
| Train | 如何购买高铁票 |
| Metro | 如何坐地铁 |
| Hotel | 如何入住酒店 |
| Food | 如何点外卖 |
| SIM | 如何买电话卡 / eSIM |
| Emergency | 紧急求助 |

## 功能二：Alipay 支付通关指南

### 用户痛点

外国用户不知道：

- 如何绑定国际银行卡；
- 为什么支付失败；
- 是否需要实名认证；
- 如何查看余额；
- 如何退款；
- 如何避免风控。

### 功能设计：分步指南

**示例：如何绑定 Alipay**

1. Download Alipay；
2. Sign up with international phone number；
3. Go to "Bank Cards"；
4. Add Visa / Mastercard；
5. Enter card information；
6. Verify with SMS；
7. Start payment.

### 需要标注的重点

- 哪些卡支持；
- 单笔限额；
- 月度限额；
- 哪些商家可能不支持；
- 被风控后怎么办；
- 退款到哪里；
- 如何联系客服。

## 功能三：打车通关指南

### 用户痛点

- 不会输入中文目的地；
- 不知道如何切换英文；
- 不知道司机是否接单；
- 不知道如何联系司机；
- 不知道上车点在哪里。

### 功能设计

1. 如何下载 / 打开打车工具；
2. 如何设置英文目的地；
3. 如何选择上车点；
4. 如何查看车牌号；
5. 如何联系司机；
6. 如何取消订单；
7. 如何支付。

### 双语卡片示例

| 英文 | 中文展示 |
|---|---|
| I am at Exit B. | 我在 B 出口。 |
| I am wearing a black jacket. | 我穿着黑色外套。 |
| Please wait 2 minutes. | 请等我 2 分钟。 |
| I don't speak Chinese. | 我不会说中文。 |
| Please show this to the driver. | 请把这段给司机看。 |

## 功能四：高铁票购买指南

### 用户痛点

- 不知道如何使用 12306；
- 不知道护照如何购票；
- 不知道候补票是什么意思；
- 不知道如何取票 / 进站；
- 不知道如何选座。

### 功能设计

1. 如何注册 12306；
2. 如何填写护照信息；
3. 如何搜索车次；
4. 如何理解「候补」；
5. 如何选座；
6. 如何支付；
7. 如何进站；
8. 如何改签 / 退票。

### 重点解释：候补票

对很多外国人来说，「候补票」很难理解。需要用简单英文解释：

> Waitlist means you pay first. If another passenger cancels, the system may automatically get a ticket for you.

## 功能六：酒店入住指南

### 用户痛点

- 不知道酒店是否能接待外国人；
- 不知道怎么办理入住；
- 不知道怎么填地址；
- 不知道怎么联系前台；
- 不知道如何展示护照。

### 功能设计

1. 预订前如何确认酒店可接待外国人；
2. 入住时需要准备什么；
3. 如何填写入住信息；
4. 如何询问早餐、押金、退房；
5. 如何让前台帮忙叫车；
6. 如何请前台帮忙翻译。

### 常用沟通卡片

| 英文 | 中文 |
|---|---|
| I have a reservation under my passport name. | 我用护照预订了房间。 |
| Could you help me check in? | 请帮我办理入住。 |
| What time is breakfast? | 早餐几点？ |
| Do I need to pay a deposit? | 我需要付押金吗？ |
| Can you help me call a taxi? | 可以帮我叫车吗？ |

## 功能八：双语急救卡片（产品亮点）

当外国用户遇到沟通困难时，可以一键展示中文卡片。

### 场景分类

1. 打车；
2. 外卖；
3. 酒店；
4. 医院；
5. 丢失物品；
6. 手机没电；
7. 找路；
8. 报警 / 求助。

### 示例

**打车卡片**

> 你好，我不太会说中文。
> 请带我去这个地址：
> [地址]
> 谢谢！

**医院卡片**

> 你好，我身体不舒服。
> 请帮我看一下。
> 我对 [药物/食物] 过敏。
> 我的护照号码是：[号码]。

**求助卡片**

> 你好，我的手机快没电了。
> 请帮我联系我的朋友。
> 他的电话是：[电话号码]。
> 非常感谢！

## 功能九：避坑指南

| 场景 | 避坑建议 |
|---|---|
| 打车 | 不要只写 "Hotel"，最好写酒店英文名 + 中文地址 |
| 高铁 | 护照购票可能需要人工核验，建议提前到站 |
| 支付 | 部分小摊可能无法使用外卡，建议准备少量现金 |
| 酒店 | 预订前确认是否接待外国人 |
| 外卖 | 地址最好写酒店名 + 房间号 + 前台联系方式 |
| 地铁 | 高峰期人多，注意避开早晚通勤 |
| 景区 | 部分景区需要提前预约，不能现场买票 |

## 功能十：城市快速包

不同城市生活细节不同，可以做城市包。

### 覆盖城市（示例）

上海、北京、苏州、杭州、广州、深圳、太仓、南京

### 每个城市包包括

1. 机场 / 高铁站到市区指南；
2. 地铁 / 公交使用方式；
3. 推荐打车方式；
4. 外国人友好医院；
5. 常用酒店区域；
6. 常见景区预约规则；
7. 本地紧急联系电话。
