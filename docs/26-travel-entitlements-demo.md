# 独立旅行买断权益 Demo

## 产品范围

- 会员中心 `/upgrade` 提供“会员续费 / 旅行买断权益”两个入口，个人中心可直达旅行权益。
- 接机、通信卡、寄存、本地文化体验均可独立购买；Free、Plus、Pro 不区分购买资格，也不修改会员到期时间或 AI 额度。
- “买断”指一次购买获得一项约定范围内的一次服务，不是终身无限次服务，不自动续费。
- 每项展示专属客服对接：双语准备清单、办理流程说明、统一咨询入口。Mia 是虚构的演示客服；选问题只写入本机记录，不会发送消息。
- 当前没有支付接入、合作商、服务库存、真实预约、发券或核销。购买实际支付金额始终为 $0。所有页面、确认操作和记录均说明演示性质。

## 状态与存储

- `domain/travel-services.ts`：四语言完整目录、公开价格来源、固定汇率、整数美分计算和演示文案。
- `Profile.travelOrders`：每个本机账户独立保存；旧存档缺少此字段时视为空，不影响原有会员开通记录。
- `buyTravel`：只校验登录／本机数据及服务 ID，不检查会员等级。相同 checkout ID 与服务 ID 重复调用只生成一单；保存价格快照、实付 0。
- `requestTravelSupport`：只能修改当前账户自己的演示记录；保存问题种类与时间，回应来自本地预设内容。
- 未登录可在确认区一键使用已有 Demo 账户并体验；会员变化仅来自原有 Demo 登录行为，买断函数不操作会员。
- 刷新后买断与客服演示记录仍保留；AI Key、模型配置和聊天沿用运行内存策略，不进入这些记录或持久化结构。
