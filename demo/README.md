# ChinaPASS Demo

在线版入口：<https://11kaize.github.io/ChinaPASS/>

ChinaPASS 面向来华访客，提供行前准备清单、双语沟通短句和紧急拨号入口。核心短句仍支持离线访问，也可以全屏展示给身边的人看。

## 当前功能

- 浏览 8 个实用旅行场景，查看操作步骤、常见问题、备选方案和官方来源
- 搜索并浏览 12 组共 82 条中英双语短句
- 收藏常用短句，保存到本机
- 将中文短句全屏展示，隐藏英文、复制中文、键盘翻页
- 勾选五项行前准备清单，状态保存在本机
- 查看 7 条常见问题，记录各场景的逐步完成情况
- 从首页拨打 110 报警、120 急救、119 火警或 122 交通事故电话，或打开中文求助卡
- 将网站安装为 PWA，缓存静态应用资源供离线使用
- 使用 Electron 将同一静态页面打包为桌面应用，参阅仓库根目录 [DESKTOP.md](../DESKTOP.md)

## 本地运行网页

在 `demo/` 目录执行：

```bash
python3 -m http.server 4173
```

打开 <http://localhost:4173>。直接打开 `index.html` 也能使用短句与清单；PWA 安装和 Service Worker 离线缓存需要通过 HTTP 或 HTTPS 访问。

## 内容边界

当前 Demo 不提供地图导航、付款、打车、铁路订票、实时翻译或紧急调度服务。短句仅用于沟通；政策及服务可用性会变化，出行前请查看相关服务方的最新说明。

数据放在 `data.js`，界面和交互分别位于 `app.js` 与 `styles.css`。PWA 清单和缓存分别位于 `manifest.webmanifest` 与 `sw.js`。更新离线内容时，递增 `sw.js` 中的缓存版本号。
